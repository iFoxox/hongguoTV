# 相关作品与下一季预约

相关作品已由用户验收并合并 main。原开发分支为 `feature-related-works`，验收包为 `0.0.6-related-works` / versionCode 22。本文保留协议和验证边界，不作为当前 APK 版本说明。

## 已核对的读取协议

公开相关作品接口：`GET /reading/bookapi/plan/v:version/`，`scene=10`、`from=detail_page_more_related`、`book_id=当前剧集编号`。设备参数、签名与已有内容请求保持一致。2026-10-22 用公开剧集数据验证可返回同系列第二季、第三季；不使用账号凭据。

相关卡片位于 `show_type=547` / `cell_name=相关作品` 的 `video_data`。`content_type=1004` 是可播放短剧；`1007` 是待上线预约作品，即使 `disable_play=false` 也不能据此播放。`series_id` 是季编号，`season_index` 和 `tag_info.text` 是季标记。解析保留接口返回的全部有效作品及其顺序，排除小说、音频和重复项；TV 详情页与手机播放页均保留并标记当前作品，当前卡片不重复跳转。官网的「同IP」保留原样，不将其当作同一部剧的季数。

参考协议来源：charlie901208/HGTV 的 feat/phone-login 分支（GPL-3.0-only）中 relatedRows / parseRelatedRows。新增解析、界面、账户状态隔离与测试为本项目实现。

读取遇到空响应最多换三条线路重试；成功结果只在内存缓存最近八部，手动刷新绕过缓存。TV 详情页与手机播放页共用完整列表和上一季定位规则。若官网没有返回当前季，则仅在当前标题的季数与接口相邻季标记能对应时插入当前位置，否则把当前作品放在开头；找不到带官方季标记的上一季时也从开头展示。加载失败提供重试，不阻塞当前剧集播放。跳转已上线作品沿用详情与本机续播流程，待上线作品沿用账号预约流程。2026-10-28 已用多季剧集验证相关作品接口；真实手机／TV 界面和预约结果仍需用户验收。

M25 TV 入口沿用详情页选集下方的「相关作品」，不增加播放遮罩。第 9 季可对应第 8 季时，横向列表先滚到第 8 季附近，选集向下与刷新向下进入该卡片；初次加载只横向定位，不自动滚动整个详情页或抢走播放／选集焦点。左右遍历全部作品，首尾不循环，上键到刷新，再向上回选集；刷新向下回最后浏览卡片。刷新、失败与空状态保持刷新可聚焦，成功后恢复仍在列表中的浏览目标。

M25 自动化验证：`:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug` 全部通过，core 204 项、app 249 项测试无失败；相关作品 UI 回归在 API 23／26 检查完整列表、当前作品、上一季定位、不抢选集焦点、刷新恢复与失败重试。Lint 0 错误、64 项警告。测试 APK 保持 `io.github.tsukiyo_zero.guoyingtv`、`0.1.9 / 50`，与 M24 Debug 证书一致，并通过 API 23／26 签名校验；这些检查不替代真实设备与账号验收。

## 预约写入仍需实际账号验证

根据公开官方 RPC 模型 SearchUncoverSubscribeRequest 接入 `POST /reading/bookapi/search/uncover_subscribe/v1/`，提交 gzip JSON 和当前登录态。测试包采用数值型 `item_id=目标季 series_id`、`item_type=3`、`op_type=1`、`subscribe_source=0`。字段名可由模型核对，但这些操作取值及跨设备实际效果尚未在真实账号验证，不能把自动化请求格式测试当作官方 App 同步成功。

`code=0` 只显示“红果已接受预约请求，尚未在账号列表确认”。不乐观插入预约列表；只有当前账号预约列表中出现该季编号才显示“已预约”。未确认时可手动刷新，避免连续写入。列表每类读取最近 20 条，未出现不能证明从未预约。退出和切换账号会清除已接受但未确认的状态。暂不提供取消预约。

## 手动验收

由用户安装 APK 后操作，不自动安装或操作模拟器。

1. 长按剧集 → 查看剧集详情，向下到“相关作品”。确认其他季及待上线作品正常展示，小说不展示。
2. 打开已上线季，应进入其详情，返回后回到原季；遥控器可在选集、相关卡片、刷新按钮间移动。
3. 未登录时点预约，进入现有登录流程；完成后重新点击目标作品。
4. 选择一个手机上尚未预约的作品提交。截图记录接口提示，并在手机官方 App 核对；之后在电视刷新预约状态，核对是否显示已预约。未确认之前不声称新增预约已接通。
5. 退出或切换账号，确认不会显示前一账号的预约状态。
6. TV 打开第 9 季详情：选集向下到相关列表应落在第 8 季附近，当前第 9 季有「当前作品」标识且确认键不重复打开；持续左右可遍历完整列表和同 IP 作品，原有选集、收藏、简介仍可使用。
7. 浏览到另一张相关卡片后，上键到刷新、下键回该卡片；刷新成功后仍落在该作品。网络失败后刷新可重试，无法匹配的标题从开头展示，不把同 IP 或无季标记的相邻项当作上一季。
